Permissions, roles and options

Delegated Graph permissions (read-only)

  • CopilotCostManagement.Read.All
  • CopilotCostManagement-Policy.Read.All
  • CopilotCostManagement-Assignment.Read.All
  • CopilotCostManagement-UserData.Read.All
  • GroupMember.Read.All
  • User.ReadBasic.All
  • User.Read

Uses the Microsoft Graph Command Line Tools app. A Global Administrator may need to grant admin consent once; that consent stays in the tenant after the run and can be removed in Entra (Enterprise applications › Microsoft Graph Command Line Tools › Permissions). The signed-in account needs a role that can read Copilot billing data, for example Global Reader, Billing Administrator or AI Administrator.

The output file is sensitive. It contains names, UPNs, group names, per-user spend and alert recipient addresses. Keep it confidential and do not share it publicly or commit it.
